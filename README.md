# 深圳金鑫绿建股份有限公司 企业网站

本仓库是深圳金鑫绿建股份有限公司的中文企业网站源码，基于 Astro + Tailwind CSS 构建。网站内容覆盖五类钢结构业务、71 个工程案例、85 条新闻记录、公司资料与联系方式，并只使用经确认可公开的公司事实、项目资料与图片。

## 页面结构

- `/` 首页
- `/products/` 钢结构业务（5 条业务方向，含各自详情页）
- `/projects/` 业务与案例（71 个工程项目，分类、关键词筛选及每页 12 项分页；保留原有详情地址）
- `/news/` 新闻中心（85 条历史新闻，按日期排序并分页）
- `/about/` 关于金鑫
- `/contact/` 联系我们

## 环境要求

- Node.js 22+
- npm 10+

## 命令

```bash
npm ci --include=optional
npm run dev
npm run verify:quick
npm run verify
```

## 内容说明

- 公司事实与联系方式来自 `src/data/company.json`，不要在页面组件中重复硬编码。
- 业务方向内容位于 `src/content/products/`，工程案例内容位于 `src/content/projects/`。
- 公开图片位于 `public/media/`；原始资料与内部记录保留在 `materials/` 与 `notes/`，两者均为私有输入。
- 网站以 `https://gsin.fuliang.online/` 为规范域名，使用 `production` 模式；普通页面允许索引，404 页面保持 noindex。每次构建根据实际可索引页面生成 `/sitemap.xml`，robots.txt 声明站点地图，Google 所有权验证文件永久保留。

- 首页按原官网复刻，使用 `src/data/original-home.html` 与 `public/replica/` 中的原始样式、fullpage 和 Flexslider 运行逻辑：滚轮整屏切换、五张工程轮播图及圆形方向箭头与圆点、公司介绍和三栏业务的分阶段入场、新闻及页脚切换。图片和视频均连接本地公开资产，业务入口连接合并后的分页案例库。
- 公司介绍按完整原文拆为六个章节，发展历程保留全部 21 条记录；资质与荣誉汇总跨分页资料，支持分类及图片放大。技术体系增加结构分解、建造流程和应用工程，新闻列表与详情统一阅读版式。
- `scripts/sync-presentation-data.py` 从授权的原站副本生成首页与企业展示数据，沿用公司介绍视频和历史统计口径。统计数据标注历史来源，未将其更新为未经核实的新数字。
- 原有业务、案例、新闻、关于与联系页面的地址及内容继续保留，使用统一的新导航和页脚。
- `src/data/archive.json` 保存原官网 213 个内容页面的公开资料及来源，`src/data/assets.json` 保存图片来源与本地文件的映射；共导入 828 个公开图片资产，其中本轮从 copy-gsin 补回 35 个。
- 来源仓库为 https://github.com/paofu456/copy-gsin 。`scripts/sync-original-catalog.py` 可从本地来源仓库复核并生成工程、新闻目录及六个历史别名页面。原始副本保存在忽略目录 `.tmp/source-copy`。
- 工程详情展示原始概况、参数、全部工程影像和相关工程，另可展开查阅完整原站记录。业务页介绍服务范围与技术体系，业务详情通过分类入口连接工程案例库，不再重复铺设案例图库。
- 原官网的公司介绍、发展历程、资质、荣誉、技术体系、专利、工程案例与历史新闻通过原有 `.html` 地址提供。
- Astro 使用文件输出保留历史 `.html` 地址；配置中的 `preserve-clean-urls` 构建钩子将现有无扩展名页面归位到 `目录/index.html`，保持 `/products/` 等原有链接可用。
- 联系方式继续以 `src/data/company.json` 为准；历史企业数据和证书资料有历史资料说明。
- 来源仓库中 18 条新闻的文字正文为空；保留已有标题、日期和可用图片，不生成新闻正文。完整新闻稿和最新证书需由客户补充。
- 本轮修改为本地交付，未推送 GitHub 或部署线上。
